Curso Híbrido Colaborativo de Python y SQL

Bienvenido al repositorio oficial del Curso Híbrido Colaborativo de Python y SQL, un espacio diseñado para el aprendizaje práctico, estructurado y colaborativo en análisis de datos y bases de datos.

Este curso combina sesiones presenciales y virtuales, promoviendo el trabajo en equipo, el aprendizaje activo y el desarrollo de proyectos reales.

🎯 Objetivos del Curso

Comprender los fundamentos de programación en Python

Dominar consultas y manipulación de datos con SQL

Integrar Python y SQL para análisis y gestión de datos

Desarrollar proyectos colaborativos con buenas prácticas

Utilizar herramientas de control de versiones (Git y GitHub)

🚀 Cómo Empezar

Clona el repositorio:

git clone https://github.com/usuario/curso-python-sql.git


Crea tu entorno virtual:

python -m venv venv
source venv/bin/activate  # Mac/Linux
venv\Scripts\activate     # Windows


Instala dependencias:

pip install -r requirements.txt
